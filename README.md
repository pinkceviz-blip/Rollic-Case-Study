# Bus Jam — Rollic Case Study

Portrait Unity puzzle game with ten levels, a level editor, Turkish / English settings, local save/resume and rechargeable lives.

## Quick start

1. Install Unity Hub and **Unity 6000.6.0f1**.
2. Clone this repository and add its root folder in Unity Hub.
3. Wait for package restore and asset import.
4. Open `Assets/Scenes/BusJam.unity`.
5. Choose a portrait Game view (for example 1080 × 1920), press Play, and select PLAY.

```sh
git clone https://github.com/pinkceviz-blip/Rollic-Case-Study.git
cd Rollic-Case-Study
```

The repository is private, so cloning requires access. No API key or backend setup is needed to play locally. For the complete installation, build instructions, troubleshooting, gameplay, level editing and validation notes, see [README-BusJam.md](README-BusJam.md).
